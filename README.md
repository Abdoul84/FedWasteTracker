# FedWasteTracker
Tracks federal spending flows to spot waste—built in 48 hrs for DOGE.

- **Data**: USAspending.gov API ($1M+ contracts).
- **Tech**: Python (Pandas), Flask, Tableau (Sankey).
- **Viz**: [Tableau Link](https://public.tableau.com/views/fed_spending/Sankey_View?:language=en-US&:sid=&:redirect=auth&:display_count=n&:origin=viz_share_link)
- **Setup**: `pip install -r requirements.txt`, `python src/scrape.py`, `python src/app.py`.
